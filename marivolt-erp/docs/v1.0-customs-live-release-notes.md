## Customs Phase 0 — Foundation

- Feature flag: `CUSTOMS_ENABLED=true` (`backend/src/config/customsConfig.js`)
- Data models: `CustomsLot`, `CustomsLotItem`, `CustomsMovement`, `CustomsInvoice` (schema)
- Service layer: inbound lot creation, GRN cancel guards, FIFO helpers
- RBAC permissions: `CUSTOMS.view`, `CUSTOMS.create`, `CUSTOMS.cancel`, `CUSTOMS.reconcile`
- API routes registered at `/api/customs/*` when enabled
- GRN post/cancel integration: customs lots created or reversed only when enabled and customs payload is present
- Company-scoped queries on all customs data (Marivolt / Okeanos isolation)

---

## Customs Phase 1 — GRN Integration

- Automatic `CustomsLot` + `CustomsLotItem` + `INBOUND` `CustomsMovement` on GRN post
- `REVERSAL` movements on GRN cancel when no outbound consumption
- Block GRN cancel when customs stock has been consumed
- No change to standard GRN flow when customs fields are blank

---

## Customs Phase 2A — GRN Customs Capture UI

**Store → GRN (from PO)**

Optional **Customs Information** section:

- Header: BOE, BL/AWB, supplier invoice no/date, COO, HS code, currency, unit price, weight, remarks
- Document uploads: BL copy, supplier invoice, packing list, other documents (S3 via `/documents/upload`)
- Per-line overrides: HS code, COO, unit price, currency, weight
- Payload sent only when at least one customs field or document is filled

**Backend**

- Extended `customsService` document and line-level normalization
- Document link permissions for customs uploads

---

## Customs Phase 2B-A — Customs Stock

**Navigation:** Customs → Customs Stock (`/customs/stock`)

Excel-style inbound register with columns:

- BOE, AWB, date, supplier, invoice no, COO, article, part name/number, HS code
- Currency, unit price, qty imported, weight, total value
- Customs stock / customs stock balance, remarks, status

**Features**

- Search, filters (supplier, COO, status, date range), pagination, CSV export (up to 5,000 rows)
- Actions: view BL copy, supplier invoice copy, linked GRN
- Data source: `CustomsLot` + `CustomsLotItem` + movements

---

## Customs Phase 2B-B0 — Customs Stock Ledger

**Navigation:** Customs → Customs Stock Ledger (`/customs/stock-ledger`)

Movement register from `CustomsMovement`:

- Types: `INBOUND`, `OUTBOUND`, `ADJUSTMENT`, `REVERSAL`
- Reference types: `GRN`, `CUSTOMS_INVOICE`, `MANUAL_ADJUSTMENT`
- Qty in/out, running balance, user, remarks

**Features**

- Filters: company, date range, article, part number, supplier, BOE, BL, AWB, movement type
- CSV export
- Acceptance: every customs stock change appears in the ledger

---

## Customs Phase 2C — Customs Invoice

**Navigation**

- Customs → Customs Invoices (`/customs/invoices`)
- Sales → Sales Invoice detail → Customs Invoice panel

**Capabilities**

- Create customs invoice from posted sales invoice
- Company numbering: `MAR-CUS-00001`, `OKE-CUS-00001`, …
- **AUTO FIFO** allocation by supplier invoice date (null dates sort last)
- **Manual multi-BL** allocation with admin override on insufficient stock
- Draft → finalize → cancel with stock reversal
- `OUTBOUND` / `REVERSAL` ledger movements
- Searchable PDF print (`/customs/invoices/:id/print` + report PDF service)
- Audit trail on create, update, finalize, cancel
- Eligibility check before re-create after cancel

**API highlights**

| Method | Path |
|--------|------|
| GET | `/api/customs/invoices` |
| POST | `/api/customs/invoices/from-sales-invoice/:salesInvoiceId` |
| PUT | `/api/customs/invoices/:id` |
| POST | `/api/customs/invoices/:id/finalize` |
| POST | `/api/customs/invoices/:id/cancel` |
| GET | `/api/customs/available-lots` |
| GET | `/api/customs/invoices/:id/print` |

**Production audit** (`backend/scripts/customsPhase2cAudit.mjs`)

- 18 passed, 0 failed, 4 warnings (test-data gaps only)
- FIFO, manual allocation, cancel/reversal, permissions, company isolation, PDF generation verified
